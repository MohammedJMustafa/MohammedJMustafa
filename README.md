## About

I build enterprise software and run the infrastructure it lives on.

For the past few years I have administered the Windows Server, Oracle, and virtualization stack behind a bank's core operations, while designing and shipping the applications that sit on top of it. That combination shapes how I write software: I think about deployment, backups, and the 3 a.m. failure case while the code is still being written.

Currently finishing a Bachelor of Information Systems Engineering at Erbil Polytechnic University.

## Public Projects

### [Nonlinear Root Finder](https://github.com/MohammedJMustafa/nonlinear-root-finder)

<img src="https://img.shields.io/github/v/release/MohammedJMustafa/nonlinear-root-finder?style=flat-square&color=0F4C81&label=release" alt="latest release" />
<img src="https://img.shields.io/github/license/MohammedJMustafa/nonlinear-root-finder?style=flat-square&color=2E6DA4" alt="license" />
<img src="https://img.shields.io/github/languages/top/MohammedJMustafa/nonlinear-root-finder?style=flat-square&color=3776AB" alt="top language" />

Educational desktop application for the Newton-Raphson and secant methods on scalar nonlinear equations. Step-by-step iteration control, live convergence plots, symbolic derivatives through SymPy, and CSV or Excel export of iteration tables. Built with PySide6 and shipped as Windows, macOS, and Linux builds through GitHub Actions.
